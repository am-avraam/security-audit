# Роли в Kubernetes

| Роль | Права роли | Группы пользователей |
|------|------------|---------------------|
| cluster-admin | Полный доступ ко всем ресурсам кластера | Администраторы кластера |
| view-only | Только просмотр всех ресурсов кластера (get, list, watch) | Аудиторы, DevOps-инженеры только для чтения |
| namespace-admin | Полный доступ к ресурсам в рамках своего namespace | Команды разработки (по доменам) |
| secrets-manager | Доступ к работе с секретами (get, list, watch, create, update, delete secrets) | Команда безопасности |
| deployment-manager | Управление деплоями (get, list, watch, create, update, delete deployments) | DevOps-инженеры |

## Пояснения к ролям:

1. **cluster-admin**:
   - Высший уровень доступа
   - Может управлять всеми ресурсами кластера
   - Предназначена для администраторов кластера

2. **view-only**:
   - Только просмотр ресурсов
   - Нет прав на изменение
   - Подходит для аудиторов и мониторинга

3. **namespace-admin**:
   - Полные права в рамках своего namespace
   - Каждый домен (продажи, ЖКУ, финансы, дата) получает свой namespace
   - Команды работают только в своем namespace

4. **secrets-manager**:
   - Специальная роль для работы с секретами
   - Повышенные привилегии для команды безопасности
   - Может управлять секретами во всех namespace

5. **deployment-manager**:
   - Роль для DevOps-инженеров
   - Может управлять деплоями и сервисами
   - Работает во всех namespace
